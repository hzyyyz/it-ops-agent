# 简单 Web 前端设计

## 目标

按总计划提供可直接使用的浏览器页面：历史会话、流式聊天、知识库管理和 Agent Trace。现有 Streamlit 保留；新增页面由 FastAPI 同源提供，避免跨域和独立构建服务。项目目前是本地单用户模式，页面和管理 API 沿用这一约束，不把服务直接公开到公网。

## 方案选择

React/Vue 构建需要 Node 依赖和新的部署步骤；当前没有前端包管理项目，且页面交互规模很小。采用原生 HTML/CSS/JavaScript 静态页面，FastAPI 提供 `/ui`，浏览器通过同源 `/api` 通信。它保留日后改为 React/Vue 的空间，同时使这一步可以直接运行。

## 数据流

聊天调用现有 `POST /api/chat/stream` 并解析 `delta/done/error` SSE；只有收到 `done` 才把用户消息和回答视为已保存，并刷新会话列表。侧栏读取、切换、删除会话，删除前二次确认。知识库接口列出 `data/` 顶层允许的 txt/pdf 文件，提供安全文件名校验、大小限制、上传、删除和重新同步；后端复用增量索引服务，拒绝目录穿越。Trace 接口只按本次请求的 `trace_id` 返回结构化允许字段，不返回问题、回答或工具结果正文。

## 错误与验证

上传或删除后若索引失败，页面显示明确错误，文件状态可由列表看到，用户可重试同步。会话冲突、SSE 中断和后端不可用有可读提示。使用 API 测试覆盖静态入口、文件校验/上传/删除/同步与 Trace 隐私；用浏览器或本地静态检查验证页面主流程。Docker API 已映射本机 8000 端口，页面地址为 `http://127.0.0.1:8000/ui`。
