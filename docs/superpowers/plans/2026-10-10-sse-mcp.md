# SSE and MCP Implementation Plan

**Goal:** Stream chat answers into Streamlit and move host-monitoring tools behind a separate MCP server.

**Architecture:** Keep the existing JSON chat endpoint. A new SSE endpoint emits answer deltas and a final committed session ID; incomplete generations never create a saved turn. An MCP HTTP service owns four bounded psutil tools, while LangChain invokes them through MCP client proxies.

**Tech Stack:** FastAPI StreamingResponse, httpx, Streamlit write_stream, LangGraph streaming, MCP Python SDK, SQLAlchemy, pytest.
